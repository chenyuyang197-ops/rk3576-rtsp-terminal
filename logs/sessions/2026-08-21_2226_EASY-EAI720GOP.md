# 会话：EASY-EAI 对照 — 背景杂音 + 偶发糊帧

**日期**：2026-08-21  
**目标**：对照 `EASY-EAI-Toolkit-C-Solution/solu-rtspIPCamera` 分析 v2 背景杂音与偶发糊帧，移植可行策略并录 v3。

## 1. EASY-EAI 结论

| 项 | EASY-EAI | 说明 |
|----|----------|------|
| 音频降噪/AEC | **无** | 仅 `ai_init` + FFmpeg AAC 64k，无 volume/AGC |
| 视频采集 | `rgbcamera_init(720,1280,270)` 直出 NV12 | 无 1080p→720 scale |
| ISP 预热 | 跳过前 **10 帧** | `while(skip--) rgbcamera_getframe` |
| H.265 | `AdvanceWorkPara=NULL` | GOP 默认 2×fps，码率自动 |
| 帧 pacing | 每帧 `usleep(10ms)` | 人为限帧，非质量优化 |

**根因（相对 v2）**：我们 `volume=4.0` + Capture 80% 放大了底噪；1080p 再 scale 到 720×1280 引入软化；GOP=60 + qp-max=38 时 P 帧仅 ~2KB 更易糊。

## 2. 改动（v3）

- `publisher.ini` / `publisher_camera_record.ini`：`cameraWidth=720 cameraHeight=1280`，直采去 `videoscale`
- `encoder_main.c`：启动前 `ENC_CAM_SKIP_FRAMES=10` 预热丢帧；音频链 `audiocheblimit high-pass 120Hz → audioconvert → volume 3.0 → voaacenc 96k`；H.265 `gop=fps bps=3M qp-init=24 qp-max=34`
- `run_rtsp_av_record_board.sh`：Capture 75%，默认 env 见脚本
