## 二、简历对齐自环（720×1280 / 554 / RGA）

### 数据流

```
publisher_supervisor（读 publisher.ini）
  ├─ net_init（end0 静态 IP，INI）
  ├─ encoder 720×1280 彩条 → H.265 AU → 发布 shm 0x5200
  └─ rtsp_server :554（Live555，新流 flush 队列）
         ↓ RTSP
preview_supervisor（读 loopback.ini，预览 shm 0x5300）
  ├─ rtsp_channel 0 ─┐
  ├─ rtsp_channel 1 ─┤→ 预览 shm
  └─ player（MPP 解码 + display_rga 5s/40ms）
         ↓
  /tmp/ch0.yuv  /tmp/display_720x1280.yuv
```

### 执行命令

```bash
bash audio-video/rk3576-rtsp-terminal/scripts/deploy.sh
bash audio-video/rk3576-rtsp-terminal/scripts/run_resume_demo.sh
```

板端等价：`scripts/run_on_board.sh`

encoder 720 1280 25 0

## 四、已知限制（面试如实）

1. 视频源为 **testpattern**，非 MIPI（IMX415 计划接入）  
2. **ch1** 双路同 URL 自环时 RTSP 双客户端曾遇 TCP 缓冲/无 IP 问题，已加 net_init + H.265 AU 切分 + 预览 shm 分离  
3. **AAC** 轨未在本次视频自环中严格验收  
4. RGA 输出为 **YUV dump**，非 HDMI 实屏  
5. 无 30 min 压测数据
