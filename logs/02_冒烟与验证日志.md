# 冒烟与验证日志

> 注：早期冒烟为 **1280×720**；简历对齐后工程默认 **720×1280**，见 `03`、`07`、`08`。

## 阶段 0：GStreamer / ALSA 冒烟（计划第 1 步）

执行环境：WSL adb → 板子 Ubuntu 24.04

### H.265 硬编彩条

```bash
adb shell 'gst-launch-1.0 -e videotestsrc num-buffers=90 ! \
  video/x-raw,format=NV12,width=1280,height=720,framerate=25/1 ! \
  mpph265enc ! h265parse ! filesink location=/tmp/t.h265'
adb pull /tmp/t.h265 /tmp/rk3576-smoke/t.h265
```

| 指标 | 结果 |
|------|------|
| 文件大小 | **1,240,063 字节**（约 1.18 MB） |
| 帧数 | 90 帧 @ 25fps（约 3.6 秒） |
| 结论 | ✅ MPP 硬编链路正常 |

### 板载麦克风录音

```bash
adb shell 'arecord -D hw:0,0 -f cd -r 44100 -c 2 -d 3 /tmp/mic.wav'
adb pull /tmp/mic.wav /tmp/rk3576-smoke/mic.wav
```

| 指标 | 结果 |
|------|------|
| 文件大小 | **529,244 字节** |
| 格式 | S16 LE, 44100 Hz, Stereo, 3 秒 |
| 结论 | ✅ ES8388 声卡录音正常 |

本地留存：`/tmp/rk3576-smoke/t.h265`、`/tmp/rk3576-smoke/mic.wav`

## 阶段 2：RTSP 发布冒烟

```bash
# 先 encoder，再 rtsp_server（顺序重要）
adb shell '/home/lckfb/rk3576-rtsp-terminal/run/encoder 1280 720 25 0 &'
sleep 2
adb shell '/home/lckfb/rk3576-rtsp-terminal/run/rtsp_server 8554 &'
sleep 3
adb shell 'gst-launch-1.0 rtspsrc location=rtsp://127.0.0.1:8554/live protocols=tcp ! \
  rtph265depay ! h265parse ! fakesink sync=false'
```

日志摘录：

```
[I] RTSP URL: rtsp://0.0.0.0:8554/live
Progress: (request) Sent PLAY request
```

结论：✅ Live555 服务可连，GStreamer 客户端能 PLAY
