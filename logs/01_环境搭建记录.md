## 2. adb 工具链（WSL + Windows）

| 环境 | 安装位置 | 备注 |
|------|----------|------|
| Windows | winget `Google.PlatformTools` 37.0.1 | USB 直连板子 |
| WSL | `~/.local/android/platform-tools/` | 需写 `~/.bashrc` |

WSL 复用 Windows adb（推荐，脚本已内置 `scripts/adb_env.sh`）：

```bash
source audio-video/rk3576-rtsp-terminal/scripts/adb_env.sh
"$ADB" devices -l
```

> 说明：Windows 上 adb 正常时，WSL 内 Linux `adb` + `ADB_SERVER_SOCKET` 往往连不上 5037（adb server 只绑 localhost）。直接调 `adb.exe` 最稳。

## 5. 踩坑记录

| 问题 | 原因 | 处理 |
|------|------|------|
| WSL `adb` 找不到设备 | USB 在 Windows，WSL 不认 USB | `ADB_SERVER_SOCKET` 指向 Windows 主机 |
| 刷 TF 仍进 Android | eMMC 未擦 | RKDevTool 擦除 eMMC |
| Live555 编译缺 openssl | 板端无 libssl-dev | `genMakefiles linux-no-openssl` + `-DNO_OPENSSL=1` |
| `avenc_aac` 不存在 | Ubuntu 镜像插件集 | 改用 `voaacenc` |
| RTSP 视频 0 字节 | MPP 直编包太小 + Live555 Framer 不匹配 | 改 GStreamer 硬编 + `H265VideoStreamFramer` |
| `./rtsp_server` 找不到 | adb shell 工作目录不对 | 脚本内用 **绝对路径** |
