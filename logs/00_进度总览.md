## 与简历（`resume_preject_投递版.md`）对齐度

| 要点 | 实现 | 状态 |
|------|------|------|
| 多进程 fork/exec + wait | supervisor + PID/退出码/运行时长 | ✅ |
| POSIX shm 帧路由 | meta+payload；发布/预览池分离 | ✅ |
| MPP H.265 | GStreamer `mpph265enc` | ✅ |
| AAC-ADTS 64k | `voaacenc` | ⚠️ 视频链路已验，音频常 busy |
| Live555 554 + 回调取帧 | `rtsp_server` + `ShmFramedSource` | ✅ |
| 新客户端 flush | `fq_flush` on new stream | ✅ |
| 720×1280 NV12 | encoder 默认 720×1280 彩条 | ⚠️ testpattern，非 MIPI |
| 多路 fork 取流 | 2×`rtsp_channel` 架构 | ⚠️ 架构有，ch1 稳定帧待补 |
| RGA 5s/40ms 轮巡 | `display_rga.c` → dump | ✅（无 HDMI） |
| 静态 IP 初始化 | `net_init.c` + INI | ⚠️ end0 无 carrier 时配地址 |
| 故障隔离 | kill 单路取流后 encoder/player 存活 | ✅ |
| 交叉编译 | adb push + 板编 | ⚠️ 非 sysroot 交叉链 |
